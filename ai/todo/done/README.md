# ai/todo/done/

Completed todos from `ai/todo/`. A todo moves here once its fix or feature has been applied, built, and verified - the diagnosis and design reasoning stay useful after the fact (why the fix took the shape it did, traps like re-entrancy, verification recipes), which is why these are kept instead of deleted.

Reading caveats:

- **`file:line` anchors and the "Target commit" header refer to the pre-fix tree.** They locate where the problem *was*; the current code has moved by at least the fix itself.
- The **Status** line of each doc records where the change landed (commit on `meatbeats`, plus the upstream PR if one was opened) and any deviation from the doc's proposed diff.

## Index

- [midilearn-min-max-text-format.md](midilearn-min-max-text-format.md) - MIDI Learn / macro panel Min-Max cells painted raw normalized values until first edit because the ValueToTextConverter was assigned after setValue(). Fixed with Slider::updateText() in meatbeats `598670c6d`; upstreamed as [christophhart/HISE#994](https://github.com/christophhart/HISE/pull/994).
- [midilearn-remove-assignment-button.md](midilearn-remove-assignment-button.md) - Per-row X button to remove a MIDI Learn / macro assignment, with the callAsync re-entrancy trap. Landed in meatbeats `2b615d9cb` (with a ShapeButton/closeIcon deviation from the proposed diff); deliberately kept fork-only, not upstreamed.
- [midi-automation-in-plugin-state-flag.md](midi-automation-in-plugin-state-flag.md) - Companion to the user-presets flag: MIDI CC assignments were also restored post-onInit from project XML, embedded plugin data and the DAW session chunk, wiping script-owned mappings and corrupting write-on-change persistence via the update callback. Added `HISE_MIDI_AUTOMATION_IN_PLUGIN_STATE` (default 1) in meatbeats `422dfa104`; pushed to [christophhart/HISE#995](https://github.com/christophhart/HISE/pull/995) alongside the first flag (PR closed unmerged - fork-only). Verification notes include the stock save-XML/default-preset mapping wipe (`saveFileXml` -> `initDefaultPresetManager`). Reverted in `18a87bcac` (2026-07-21), superseded by upstream `528ccf7`.
- [midi-automation-in-user-presets-flag.md](midi-automation-in-user-presets-flag.md) - MIDI learn CC assignments were forced into every user preset (saved, restored, and cleared on load with no opt-out), wiping end-user mappings during preset browsing. Added the dynamic preprocessor `HISE_MIDI_AUTOMATION_IN_USER_PRESETS` (default 1 = old behaviour) in meatbeats `bd6cfc9c7`; PR [christophhart/HISE#995](https://github.com/christophhart/HISE/pull/995) closed unmerged - fork-only. Both flags reverted in `18a87bcac` (2026-07-21): upstream `528ccf7` shipped the runtime `UserPresetHandler.setStateManagerProperties()` instead - see the revert section in the doc for the replacement API.
- [float-dust-in-content-properties.md](float-dust-in-content-properties.md) - Float casts in ScriptingApiContent.cpp dusted every stored control value and numeric UI property (stepSize 0.1 -> 0.10000000149011612 warped the snap grid, so a 0dB knob with a negative min stored 1.49e-6 forever). Fixed in meatbeats `b58eef722` (double-precision sanitizing + exportAsValueTree step-precision rounding); the two sanitizer hunks upstreamed as [christophhart/HISE#1011](https://github.com/christophhart/HISE/pull/1011), the rounding hunk held back as an offered follow-up. Companion .patch alongside.
- [flush-attribute-dust-in-module-tree.md](flush-attribute-dust-in-module-tree.md) - The module tree's saveAttribute/saveID macros serialized double-precision residue verbatim (Balance and BipolarIntensity both 2.081668171172169e-17 from a bipolar conversion at centre). Added flushAttributeDustToZero (|x| < 1e-9 -> 0.0, save path only) in meatbeats `d903eb22b`. Not yet upstreamed; candidate follow-up to #1011. Companion .patch alongside.
- [lfo-ignorenoteon-skips-fadein.md](lfo-ignorenoteon-skips-fadein.md) - LFO IgnoreNoteOn also killed FadeIn (fade reset only lived inside resetPhase, which note-on skipped), so free-running LFOs never faded per note. Decoupled the resets in meatbeats `3576607bc`; fork decision was option 1 (fade always retriggers, no new params, accept the IgnoreNoteOn name drift), with the design discussion and rejected alternatives kept in the doc. Fork-only for now; the doc's upstream options list stands if it ever goes to Christoph.
